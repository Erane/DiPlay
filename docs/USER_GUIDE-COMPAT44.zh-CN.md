# DiPlay 车载 CarPlay · 使用说明（体验版）

> 这是一份写给**普通用户**的说明，不需要任何技术背景。请从头往下照着做即可。
> 遇到任何一步卡住都**很正常**——这个版本主要用来收集运行记录，帮我们改进。**只要点一下「导出诊断日志」把记录发回来，就是最大的帮助。**

本说明对应：**DiPlay（compat-4.4 体验版，上游 0.2.12）**，安装后桌面图标名字可能显示为 **DiPlay** 或 **DiPlay HUD Test**。

---

## 一、需要准备的东西

1. 你的**车机**（安卓车载中控）已开机，并连上网络或开启热点。
2. 一部 **iPhone**（苹果手机）和一根**能传数据的 USB 线**（不是只能充电的那种）。
3. 这个 **DiPlay 安装包（.apk 文件）**。

---

## 二、安装（第一次）

1. 把安装包传到车机上（用 U 盘插入车机，或在车机浏览器里下载）。
2. 点开安装包。如果提示「**禁止安装未知来源应用 / 未知来源**」：
   - 选择「**允许**」或到「设置 → 安全 → 未知来源」里把浏览器/文件管理器打开，再回来继续安装。
3. 安装完成后，桌面上会出现 **DiPlay** 图标，点开它。

---

## 三、第一次打开：允许几个权限

进入后屏幕上会有几个按钮（下面第五节「选择连接方式」用到）。第一次运行连接时，系统可能弹出：

- **「允许建立 VPN 连接？」** —— 点「**允许/确定**」。这是 CarPlay 建立网络所必需的，拒绝就连不上。
- **麦克风权限** —— 点「**允许**」（用于通话和 Siri；拒绝只影响打电话，不影响投屏）。
  注意：**安卓 4.x 车机不会弹这个提示**（安装时就已经给好了），只有安卓 6.0 以上才会弹。

这些权限只在本应用内使用，**不涉及你的账号、通讯录或隐私照片**。

---

## 四、先在 iPhone 上和车机配对蓝牙（无线方式需要）

1. iPhone：「设置 → 蓝牙」打开。
2. 车机：打开蓝牙并搜索设备，找到你的 iPhone；或在 iPhone 上找到车机名字。
3. 两边都点「**配对/允许可**」，确认配对成功（两台设备都会弹提示，都点同意）。
4. iPhone：「设置 → 通用 → CarPlay 车载」（老版本在「设置 → 屏幕使用时间 → 内容和隐私 → 允许的 App → CarPlay 车载」），确保允许 CarPlay。

> 配对过之后就不用每次重配。

---

## 五、选择连接方式（在 DiPlay 首页点按钮）

首页有几个按钮，按你的情况选一个：

> 首页还有两个末尾带「开/关（重连后生效）」的按钮：「**导航播报压低音乐**」和
> 「**通话用车机喇叭和麦克风**」。它们管的是声音，不影响能不能连上；用法见第八、九节。

### 方式 A：用 USB 线连接（最简单，先试这个）

1. 点「**通过 USB 连接 iPhone**」。
2. 把 iPhone 用数据线插到车机的 USB 口。
3. iPhone 若弹出「**信任此电脑？**」→ 点「**信任**」，输入锁屏密码。
4. 屏幕下方会依次显示进度（见第七节「屏幕上会出现的提示」）。

也可以直接点「**连接手机（无线/USB 自动识别）**」，让它自动判断。

### 方式 B：无线连接（车机热点 / 共同 Wi-Fi）

1. 点「**无线（车机热点模式）**」，会弹出一个填写框。
2. 二选一：
   - **A. 车机自带热点**：在车机设置里打开热点，iPhone 连上它。
   - **B. 共同的外部 Wi-Fi（更稳妥，社区实测更容易成功）**：车机和 iPhone **连同一个 Wi-Fi**（比如另一台手机开的热点、随身 Wi-Fi、或家里路由器）。
3. 在弹出框里填**这个 Wi-Fi 的名称（SSID）和密码**，点「**保存并连接**」。
4. **连接过程中车机可能自动再弹一次「蓝牙配对」请求**（屏幕会显示「正在与 iPhone 配对」）：请在**车机和 iPhone 两边都点「配对 / 允许 / 同意」**，即使之前配对过也要再确认一次（这一步每次连接只会出现一次，最多约等 35 秒）。
5. 等待 iPhone 上出现 CarPlay 连接提示。

> 小提示：部分车机自带的热点打不开 CarPlay 需要的端口，**用「共同外部 Wi-Fi」成功率更高**。

### 先确认这台车机能不能走无线（1 分钟）

老车机的蓝牙常被描述成「只能听歌、不能传信息」。这句话本身**不能**说明无线走不通：
无线 CarPlay 不用蓝牙电话本功能（通讯录、通话、Siri 都是打包在另一条数据通道里的），
真正决定成败的是「能不能开蓝牙数据串口、配对是否真实有效、放歌时能否同时开数据通道」。

首页点「**兼容性自检（安卓版本 / 蓝牙能力）**」，里面有两条检测，结果只显示在这个页面：

- 「**检测真实安卓版本**」：告诉你这台车机**真实的** Android 版本和 API 等级。
  不少车机设置页显示的版本是 ROM 改出来的假号，以这里报的「运行时 API 等级」为准。
- 「**检测蓝牙能力（决定无线能否走通）**」：逐项检查适配器、配对、SDP 服务记录、
  三种蓝牙数据串口能否打开、能否真的连上你的 iPhone、以及放歌时能不能同时开数据通道。
  最下方的「结论」会直接说：**可以走无线 / 还有希望（附该怎么做）/ 只能走有线 USB**。

> 测试时请让 iPhone 解锁并留在车上，期间车机音频可能短暂中断；正在连着 CarPlay 时请先断开再测。
> 页面结果也会被写进运行记录，回首页点「导出诊断日志」就能一起发回。

---

## 六、如果没连上：页面上的两个救命按钮

连接页下方有「**重新连接**」和「**重启蓝牙**」两个按钮：

- 连接中断、或提示「自动重连已暂停」→ 点「**重新连接**」。
- 无线方式卡在「正在与 iPhone 配对 / 等待已配对 iPhone」→ 先点「**重启蓝牙**」，它会自动关掉再打开车机蓝牙并重连。
- 若显示「蓝牙迟迟未开启，请到系统设置检查」→ 去车机「设置」里手动把蓝牙打开，再点「重新连接」。

## 七、屏幕上会出现的提示（对照看进度到哪一步了）

| 你看到的文字 | 含义 |
| --- | --- |
| 等待 iPhone 接入 USB | 在等你把线插上 / 手机没被识别 |
| 正在请求 iPhone USB 权限 | 请允许车机访问手机 |
| 正在与 iPhone 配对 / 等待已配对 iPhone | 无线方式在等蓝牙配对完成 |
| 正在建立 iAP2 控制 / 正在挂载网络 | 正在握手，稍等 |
| **CarPlay 已连接** | 成功了！手机画面应出现在车机上 |
| 失败: …（后面一句话） | 这一步没通过，属正常，请把日志发回 |

**目前很多机型会停在中间某一步或显示「失败: …」，这不是你的操作问题**——正是我们需要记录来改进的地方。

## 八、打电话、Siri 和麦克风

车机本身不处理通话内容，它只做两件事：把 iPhone 的通话声音放出来，把车机麦克风听到的声音送回 iPhone。
需要用到麦克风的情况是：**打电话**、**唤醒 Siri**、**语音输入**。

### 听不到对方 / 对方听不到你，先试这个开关

默认情况下，CarPlay 的通话声音走「蓝牙电话音频」这条通道。**很多老车机这条通道根本不通**，
典型表现是：电话能接通、计时也在走，但**双方都没声音**，或者只有一边有声音。

这时回到 DiPlay 首页，把「**通话用车机喇叭和麦克风**」这一点一下（按钮上会显示「开」），
然后**断开、重新连接一次**。打开以后：

- 通话声音改由平时的**媒体喇叭**播放（和听歌用的是同一个喇叭）；
- 麦克风直接采集**原始声音**，不再做回声消除和降噪（这条通道在老车机上往往是坏的）。

> 两个音频按钮末尾都写着「**（重连后生效）**」：它们是在连接开始那一刻读取的，
> 所以**点完必须重新连接一次**才看得到变化，这不是没生效。
>
> 建议：如果你不确定，就两种状态各连一次、各打一通电话，把结果写进反馈里——
> 这比只说「电话没声音」有用得多。

### 反馈时请顺带写清楚

- 这个开关是**开**还是**关**；
- **你能不能听到对方**、**对方能不能听到你**（两头分开说）；
- 打的是普通电话还是微信 / 抖音语音；
- Siri 按住有没有反应（Siri 走的是同一条麦克风通道）。

## 九、导航播报时压低音乐

开车时最常见的麻烦是：手机导航说话，音乐还在响。DiPlay 默认会**在导航说话时自动压低音乐，说完恢复**。
这个功能不依赖系统的音频焦点（老车机的焦点管理经常是坏的），是自己控制的。

- 首页按钮：「**导航播报压低音乐：开/关（重连后生效）**」，点一下切换，同样**重连后生效**。
- 压低的只是**音乐这条声音**（大约压到两成音量），**导航播报本身不会变小**；通话、Siri 也不受影响。
- 想一直听完整音乐、不希望被压低 → 关掉。
- 现象是「**说了不恢复**」→ 先关掉这个开关重连一次，再把日志发回。
- 现象是「**完全不压低**」→ 多半是这台车机的导航播报和音乐走了同一条通道，属已知差异，请把日志发回。
- 按音量键时调的是车机自己的音量，和这里的压低是两回事，互不冲突。

## 十、仪表盘 / HUD 上的曲名和歌词

这一节只和**比亚迪（DiLink）车机**有关，其他车型可以跳过。显示的都是 iPhone **正在播放的那首歌**，
内容来自手机推送的播放信息（曲名、歌手、播放/暂停状态），有的来源会给出歌词行。

设置页（首页点「**设置**」）里有两个不同的开关，都在「**比亚迪导航**」分组下；
那个分组没出现时，在「**高级车辆数据**」里点「**高级车辆数据**」展开后能看到第一个：

- 「**仪表盘显示歌曲**」——在仪表盘的音乐卡片里显示曲名和歌手，并同步播放/暂停状态。
  卡片是以比亚迪的「其他」音源显示的（仪表盘不会画 CarPlay 自己的音源）。**立即生效，但需要车机开启网络 ADB**；
  ADB 没开时打开了也不会显示。
- 「**仅在切歌时显示**」——配合上一项：新歌只显示 5 秒然后清空卡片，暂停/继续不再重复显示。
- 「**HUD 显示曲名或歌词**」——送到 HUD；**无导航指引时**才显示曲名或歌词，
  导航方向和道路名称优先，播报结束再恢复。这项只有带独立 HUD 输出的车型才会出现。

> **安卓 4.x 车机（也就是本说明主要面向的老界面）没有设置页，这一节的功能都不会出现**，不是坏了。
> 若你的是 4.4 车机却想让仪表显示曲名，请把首页「版本检测」那一行和你的期望一起写进反馈。
>
> 切歌后仪表/HUD 慢一两秒、或某首歌一直不显示，多数是手机侧没推送新的播放信息，请导出日志发回。

## 十一、【最重要】把运行记录发回给我们

不管成功还是失败，都请做一次：

1. 回到 DiPlay **首页**，点「**导出诊断日志（写入存储并分享）**」。
2. 会弹出「**分享诊断日志**」，选一个发给我们的方式：**微信 / QQ 的发送文件、邮件、或保存到手机**。
3. 如果没有分享弹窗（提示「分享目标不可用」），用文件管理器到车机里找这个文件，把它拷出来发给我们：
   - 路径一般在：**内部存储根目录**（`/sdcard/` 或 `storage/emulated/0/`）下的
     `diplay-log-月日-时分秒.txt`；
   - 或这个应用目录下的：
     `/sdcard/Android/data/com.shihab.diplay.android6/files/`（同类文件）。

发回时，请顺带写上这几条信息（对定位问题最有用）：

- **车型 + 车机型号/品牌**，以及车机安卓版本。**本应用会自动帮你判断真实版本**：首页会显示一行「版本检测」，若车机设置页虚报安卓版本（例如把真实的 4.4 显示成 6.1.1），会打「⚠」提示；点首页「**诊断信息**」可看到完整的「标称版本 / 检测推定版本 / API 等级」对比。请把这一行结论一起告诉我们。
- **iPhone 型号** 和 **iOS 版本**（iPhone「设置 → 通用 → 关于本机」）。
- 你用的是**哪种方式**（USB 还是无线；无线是车机热点还是共同 Wi-Fi）。
- **卡在第几步**、屏幕上最后显示的**提示文字**。
- 有没有出现「**信任此电脑**」和 iPhone 上的 **CarPlay 连接提示**。

## 十二、隐私与安全

- 这是**体验/测试版**，不是正式发布软件，可能不稳定或连不上。
- 导出的日志只包含**运行状态和设备信息**，用于调试；**不含**你的照片、通讯录、账号密码。
- 分享日志给开发者前，你可以自己先打开 txt 看一眼再发。

## 十三、常见问题速查

- **插上没反应 / 一直「等待 iPhone 接入 USB」**：换一根**数据线**、换个 USB 口；确认 iPhone 点了「信任此电脑」。
- **弹「允许 VPN 连接」时点了拒绝**：重新点连接按钮，再弹时选「允许」。
- **无线一直搜不到 / 配对不成功**：先「重启蓝牙」；确认车机和 iPhone 连的是**同一个 Wi-Fi**；把两边蓝牙都关掉再开。
- **车机蓝牙「只能听歌，不能传信息」，无线还有戏吗？**：多数情况下有——这个说法不影响无线 CarPlay。
  在首页点「**兼容性自检（安卓版本 / 蓝牙能力）**」→「检测蓝牙能力」，按它的结论办；
  若结论是「三种数据通道都开不出来」，这台机型就只能走有线 USB。
- **显示「失败: …」或干脆没弹 CarPlay**：属当前版本的已知情况，请**务必导出日志发回**，这是推进修复的关键。
- **电话能接通但没声音（一头或两头）**：见第八节，把首页「**通话用车机喇叭和麦克风**」打开后**重新连接**再试。
- **Siri 按住没反应 / 语音输入听不到**：同一根麦克风通道；先确认没拒绝过麦克风权限，再照第八节把那个开关打开重连一次。
- **导航说话时音乐没压低，或说完不恢复**：见第九节，先看首页「**导航播报压低音乐**」是不是「开」，改完要**重新连接**。
- **仪表盘 / HUD 不显示曲名或歌词**：见第十节——只有比亚迪车机、且安卓 6.0 以上的新界面才有这一项；4.4 老界面没有这个功能。

（本说明依据 compat-4.4 分支实际界面与提示编写；界面文字若与此略有出入，以车机上实际显示为准。）
